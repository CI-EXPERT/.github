# CI-Expert | UFCG — Physical Design Track

We are a four-member team participating in the **CI-Expert Program — Physical Design Track**, based at the Federal University of Campina Grande (UFCG), Brazil.

Our project focuses on the physical implementation of an **Application-Specific Integrated Circuit (ASIC)** integrating an Analog-to-Digital Converter (ADC), a register bank, and a Serial Peripheral Interface (SPI).

The system is designed to support sensor data acquisition, digital data storage, and communication with external systems.

## Project Overview

**Architecture:** ADC → Register Bank → SPI

The project begins with an already synthesized digital design and focuses on its implementation through the ASIC physical design flow.

### Physical Design Flow

1. **Floorplanning** — Core definition, macro placement, and power planning.
2. **Placement** — Standard-cell placement and optimization.
3. **Clock Tree Synthesis (CTS)** — Clock distribution and timing optimization.
4. **Routing** — Physical interconnection and routing optimization.
5. **Signoff** — Final timing, physical verification, and design integrity checks.

### Additional Development Activities

Beyond the conventional physical design flow, the team intends to explore complementary activities, including:

- Functional verification and design validation.
- FPGA synthesis and prototyping.
- Additional implementation and verification methodologies defined throughout the project.
